\section{Extended Experiments Across Datasets}
\label{app:extended_experiments}
We compare dropout placement across datasets, architectures and training-set sizes, using five paired seeds for each profile and keeping the data split and training procedure fixed within each comparison. Table~\ref{tab:frontloaded_results} combines all available seeds for uniform and the selected front-loaded profiles, reporting the seed count separately for each evaluation. The figures below retain five seeds per profile; Table~\ref{tab:fi2010_standalone_comparison} reports the separate FI-2010 study. Section~\ref{app:benchmark_methods} gives the architectures, data splits, optimizer settings, search grids and seeds, and identifies settings that could not be recovered.

\paragraph{Choosing profiles and measuring performance.}
We tune learning rate and mean dropout separately for each profile using validation data. For each completed five-seed comparison, we average the lowest validation CE reached by each seed, then choose the nonuniform profile with the lowest average. Test CE and accuracy are measured at the epoch with the lowest validation loss in each run; we keep the chosen profile even where it loses to uniform. Of these five-seed experiments, only Tiny ImageNet 80k saved test CE at the final epoch. Results are means $\pm$ SEM and curve bands show SEM over five seeds unless stated otherwise; paired CE differences subtract uniform from the named profile. No-dropout controls have their own tuned learning rates. In the separate FI-2010 study, we instead choose the profile retrospectively from mean test CE.

\paragraph{Curves and profiles.}
The benchmark figures show training and validation curves for the first five seeds; the separate CIFAR-10 pilot uses three. Where both models appear, the MLP is above the Transformer; columns show training CE, validation CE, training accuracy, and validation accuracy. Training CE has a logarithmic axis. Training metrics average batches with dropout enabled, while validation evaluates each epoch's final weights with dropout disabled. Step early fills the earliest layers at probability $0.20$, with a partially filled last active layer when needed. Big step uses $3\bar p$ in the first third; linear profiles run between $0$ and $2\bar p$. Thus profiles can differ in both mean and peak dropout. Transformer profiles are empirical extensions; the MLP reference-field diagnostic is only a proxy.

\subsection{Speech Commands}
The MLP and Transformer share 20,020/5,005/10,010 training/validation/test examples and train for 50 epochs with zero weight decay. The balanced random clip split uses the official training subset, with most speakers shared across partitions, so it does not establish performance on unseen speakers. The selected profiles' paired differences in test CE from uniform are \(-0.136\pm0.007\) for the MLP (step early) and \(-0.036\pm0.037\) for the Transformer (big step). The five-seed minimum/final validation-loss reductions are $13.23\%/13.47\%$ and $3.33\%/6.49\%$, respectively; these differ from the extended test comparisons in Table~\ref{tab:frontloaded_results}.

\subsection{Standalone FI-2010 vanilla MLPs}
These plain feedforward ReLU MLPs flatten a $128\times40$ input window and use day 6 for training, day 7 for validation, and days 8--10 for test. Each architecture trains for 100 epochs with five paired confirmation seeds (100--104), zero weight decay, and mean dropout $0.10$ for nonzero profiles. Weights have variance $1.98/\mathrm{fan\_in}$ and biases variance $0.02$. We use validation loss with uniform dropout to choose one learning rate per architecture, then hold it fixed across profiles, including no dropout. These runs are separate from the benchmark comparison above.

Test CE, accuracy and macro-F1 are evaluated once, at the epoch with the lowest validation loss. The saved results contain means and SEMs, but no validation losses, individual seeds' test results or test curves, so we cannot report final test loss or its minimum during training. Table~\ref{tab:fi2010_standalone_comparison} gives the reductions relative to uniform, choosing the nonuniform profile retrospectively by its mean test CE and reporting accuracy for that same profile.

\subsection{CIFAR-10 profile-geometry pilot}
This small experiment compares validation performance for ten fixed profiles, including exact early/late reversals, at mean probability $\bar p=0.10$, with seeds $0,1,2$ (30 runs). Six-layer width-256 ReLU MLPs train on 4,000 class-balanced examples with 1,000 validation examples (split seed 20260812), using AdamW, LR $10^{-4}$, weight decay $10^{-7}$, batch size 75, and 75 epochs of the benchmark cosine schedule without clipping. Images use fixed channel means $(0.4914,0.4822,0.4465)$ and standard deviations $(0.2470,0.2435,0.2616)$, without augmentation. Power profiles use layer-cell centers and cap $0.20$. The manifest records the exact arrays, settings and source/split hashes; the code for this pilot is not included in the released benchmark code. We do not tune hyperparameters or evaluate on the test set, so these runs do not enter the main test comparisons.
