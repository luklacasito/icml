# Supplementary Material

This folder contains supplementary materials for two additional dropout-scheduling sweeps, over `\bar{h}` values and over network width.

## Contents

- `h_sweep/`: robustness sweep over the mean dropout field `\bar{h}`.
- `width/`: width sweep at fixed mean dropout field `\bar{h} = 0.1`.

Each folder contains the notebook, saved results, exported figures, and a folder-specific `README.md`.
